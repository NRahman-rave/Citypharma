# Citypharma

A web-based pharmacy management system developed to help manage pharmacy operations, including medicine inventory, suppliers, prescriptions, and sales records.

## 🚀 Features

- User authentication and login system
- Medicine inventory management
- Supplier management
- Medicine batch tracking
- Prescription management
- Purchase order management
- Medicine dispensing
- Audit logs
- Database management using MySQL

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP (Apache & MySQL)


## ⚙️ Installation Guide

1. Install XAMPP.
2. Copy the project folder into:
C:\xampp\htdocs\

3. Start Apache and MySQL from XAMPP.
4. Create a MySQL database.
5. Import the provided SQL file.
6. Update database settings in `config.php`.
7. Open the project:
http://localhost/CityPharma
